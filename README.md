# ColeDash

European multi-city food delivery platform with flower delivery (ColeDash Fleurs), AI bouquet builder, and merchant/driver/admin portals.

## Tech Stack

- React 19 + TypeScript
- Vite 7
- Tailwind CSS 3.4
- shadcn/ui
- Framer Motion
- Zustand (state management)

## Features

- **Customer Portal**: Browse restaurants, grocery, retail, flowers
- **AI Bouquet Builder**: Drag-drop canvas with AI florist arrangement
- **Merchant Portal**: Dashboard, orders, menu, analytics
- **Driver Portal**: Deliveries, earnings, schedule
- **Admin Portal**: Cities, restaurants, users, finance

## Development

```bash
npm install
npm run dev
```
